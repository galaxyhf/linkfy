# 🔗 Linkfy

Site organizador de links pessoais estilo Linktree, com design minimalista e moderno.

## ✨ Características

- **Design Responsivo** - Funciona perfeitamente em desktop e mobile
- **Animações Suaves** - Efeitos com Framer Motion
- **Typewriter Effect** - Texto que digita automaticamente
- **Loading Screen** - Tela de carregamento personalizada com iniciais
- **Fundo Animado** - Partículas flutuantes e gradientes dinâmicos
- **Glassmorphism** - Cards com efeito de vidro fosco
- **Totalmente Personalizável** - Fácil de editar cores, links e informações

## 🛠️ Tecnologias

- **React** - Framework JavaScript
- **TypeScript** - Tipagem estática
- **Vite** - Build tool e dev server
- **Tailwind CSS** - Estilização
- **Framer Motion** - Animações
- **Lucide React** - Ícones
